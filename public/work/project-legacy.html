LLM output verification

Check the calculations before writing the explanation.

The apps use structured inputs and published chart rules. A deterministic engine computes the chart. A separate implementation recomputes the checked values from the same source inputs without calling the production chart engine.

Compute the chart.

The engines use names, dates of birth, and an explicit target date to calculate the product’s name- and date-based chart values. They also derive timing cycles and measures for pairs of people.

Individual values
Life path, expression, birthday, and maturity numbers
Time-dependent values
Personal cycles, challenge numbers, and pinnacle values
Pairwise values
Resonance, dominant difference, and friction scores

Recompute and compare.

The independent verifier rebuilds the individual values from the published rules. It reconstructs the pairwise measures from individually verified inputs and checks timing outputs such as the forecast’s best and worst days. The verification path withholds disputed charts.

Inputs
Original records and target date
Check
Compare the chart with the independent recomputation
Disagreement
Withhold the result and report the mismatch

Explain the checked result.

A fine-tuned language model receives the computed chart and turns it into prose for the app. The verification described here covers numeric chart inputs to the model. Fidelity of the generated explanation is evaluated separately offline.
