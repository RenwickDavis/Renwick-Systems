How we build

Our work: Project Legacy

Project Legacy is a family application and a companion staff application, built end to end by Renwick Systems' founder over sixteen weeks and shipped to the stores. Its content is computed by engines from each family's own data; a set of fine-tuned language models only words the result, and a verification layer recomputes every value independently before it is served.

  • One GPU service carrying eleven fine-tuned adapters, scaling to zero between requests; one background worker; one queue.
  • About $500 a month to run, with a weekly bill read against that budget.
  • One operator, with daily and weekly routines that post the system's health, service levels and spend to a ledger.
  • A public architecture record and blameless incident reports, written the day of the incident.

Project Legacy is the founder's own product; it is the first case study, and the method it was built with is what Renwick Systems sells.
